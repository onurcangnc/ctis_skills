# Disclosure notice and usage boundaries

CTIS Skills is an independent, unofficial educational and software-assistance work. It does not mean that Bilkent University, CTIS, or any person named here has approved or endorsed the project.

## Purpose

The project was not designed to harm the department, instructors, specialists, students, the academy, or any person; to rank, imitate, discredit, evaluate, surveil, or target them. It assists at course level with coding, reasoning, document preparation, and verification.

## Information boundaries

The project has no access to private emotions, thoughts, communications, records, or non-public systems. It does not go beyond observable artifacts and official course associations. Each association is given with an evidence class, status, and confidence-bound. It does not infer emotions, intentions, mental health, personality, political views, or hidden thoughts.

The capabilities in the modules are anonymous, aggregated, shared course abilities. They do not reproduce any single person's private style and carry no claim of exclusive authorship, personal proficiency, or institutional opinion.

## Decision and responsibility boundaries

Skill output is not evidence for academic, employment, disciplinary, psychological, legal, or administrative decisions. It cannot be used to score or assess any person, course, or institution against another.

The user keeps responsibility for academic integrity, course rules, source verification, and safe use. Reviewing produced code before running it, confirming the level of help the course allows, and disclosing sources are all the user's duty.

A source, scope, name, image, or take-down/correction request can be filed through the repository issues channel. The request must name the record path and the official source for the correction.
